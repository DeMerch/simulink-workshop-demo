# Simulink Workshop Demo

This repository is a demo Quarto website created to test a wiki-style documentation setup
for a hands-on Simulink build-along workshop.

The site demonstrates how technical workshop materials can be published using
Quarto and GitHub Pages.

## Contents
- Workshop overview
- Step-by-step build instructions
- Reusable structure for future EEES events

## Tech Stack
- Quarto
- GitHub Pages
